OXY-LD2 — lib/mod_calc

Table MOD Nitrox — revue avant intégration

80 lignes (O2 21–100 %) × 2 réglages ppO2, générées par script — pas transcrites à la main. À valider avant de figer les valeurs dans mod_table.cpp.

MOD(m) = ⌊ ((ppO2 / (fO2/100)) − 1) × 10 ⌋  ·  troncature vers le bas (jamais vers le haut)

Méthode

Aucune table numérique officielle FFESSM n'existe — leur manuel de formation (mai 2024) enseigne le calcul, pas une table figée. Ces valeurs sont générées par la formule standard puis tronquées vers le bas (jamais arrondies, jamais vers le haut) : direction conservatrice, la profondeur affichée est toujours ≤ à la MOD réelle.

Validée contre la table du club

La table réellement utilisée par le club (F. Gentili / sommeildesepaves.com — pas un document FFESSM officiel) a été comparée ligne par ligne à la colonne MOD@1.6 : 78/78 valeurs identiques (22–99 %), y compris les cas groupés (46-47 %→24 m, 49-50 %→22 m).

Cette table du club ne couvre que ppO2=1.6 — pas de colonne 1.4, et elle commence à 22 % (pas de ligne 21 % ni 100 %). La colonne MOD@1.4 et les lignes 21 %/100 % restent donc formule seule, non recoupées avec un document indépendant.

Bug flottant trouvé en générant cette table

Le calcul brut en float plaçait certaines valeurs pile sur un entier (ex. 28 % → 40,0 m exact) une valeur en dessous (39.999999999 → troncature à 39) à cause de l'imprécision binaire de 1.4/0.28. Corrigé ici par une tolérance +1e-9 avant troncature — sans jamais pouvoir faire remonter une vraie valeur non-entière au palier supérieur (marge bien trop petite pour ça). Cette correction devra être reprise telle quelle dans le générateur final, sinon quelques MOD seront affichées 1 m plus prudentes que nécessaire — pas dangereux, mais incohérent avec la table de référence.
